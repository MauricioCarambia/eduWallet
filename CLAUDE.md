# EduWallet / KoleTap

## Diseño

Antes de cualquier cambio visual (colores, tipografía, componentes, landing), leé y seguí `DESIGN.md`.
Usá siempre las variables CSS (`var(--brand)`, `var(--on-brand)`, `var(--text)`…); nunca colores escritos a mano.
Si hace falta un color nuevo, agregalo en `admin/src/index.css`, `padres/src/index.css` y `pos/src/index.css`, con valor claro y oscuro, y documentalo en `DESIGN.md`.
